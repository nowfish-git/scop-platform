# @scop/miniapp-elder

> SCOP 智慧社区运营平台 — 老人端微信小程序

## 职责

- 适老化极简模式首页
- SOS 一键求助
- 健康数据查看（心率/血压/血氧/睡眠/步数）
- 我的（基本信息/家属/设备）

## 平台

- 微信小程序（主）
- 支付宝小程序（M2.0+ 可选）

## 技术栈

- Taro 4 + React 18 + TypeScript 5.4
- NutUI / Taro UI（适老化组件库）
- 微信小程序 API

## 无障碍要求

- 字体 >= 18px
- 按钮触控区域 >= 44x44px
- 符合 WCAG 2.1 AA 级

## 阶段

**M2** — 业务实现：SOS + 健康 + 我的
